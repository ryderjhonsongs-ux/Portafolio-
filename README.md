# 🐍 Utilidades en Python

Pequeña colección de scripts útiles desarrollados en Python para automatizar tareas del día a día, resolver cálculos rápidos y mantener el orden. Diseñados para correr de forma ligera (incluso en Termux).

## 📂 Contenido

1. **`calculadora_electrica.py`** - Herramienta rápida para despejar valores de la Ley de Ohm y calcular potencias.
2. **`organizador_de_archivos.py`** - Script automatizado para ordenar carpetas caóticas clasificando archivos por extensiones.
3. **`contraseña_segura.py`** - Generador de claves robustas y personalizables con longitud y símbolos opcionales.

---
*Desarrollado y optimizado para entornos móviles y de escritorio.*
